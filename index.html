4.1 – 4.2 · Notes p. 39

Every cycle is a mean plus an amplitude

Fatigue is progressive fracture under repeated cycles of stress. Unlike static failure, it usually gives no warning before the part breaks. A crack initiates near a stress concentration, propagates only while the material is in tension, and ends in sudden unstable fracture.

4.3 · Notes p. 40

Why the rotating beam test is completely reversed

In the R.R. Moore machine the polished specimen sits between the two load points, where it carries pure bending with no transverse shear. The bending moment stays fixed in space while the specimen spins, so every point on the surface travels from the tension side (bottom) to the compression side (top) once per revolution. Track point 1 below.

σ = Mc / I · cos θ

The stress at the tracked point follows σ/σmax = cos θ, with σm = 0. Each test gives one point (σa, N) on the S-N diagram.

4.4 – 4.6 · Notes pp. 41–42, 46

Building the S-N line from two points

For a specific condition we replace the test data with a straight line on log-log axes between point A (N = 103, Sf = fSut) and point B (N = 106, Sf = Se). Beyond 106 cycles a steel has infinite life. Non-ferrous metals such as aluminum have no clear endurance limit.

a = (fSut)²/Se
b = −⅓ log(fSut/Se)

Sf = aNb and N = (σa/a)1/b hold only between 103 and 106 cycles. Fully reversed factor of safety: n = Sf/σa. The f estimate fits the Fig. 6-18 curve (70–200 kpsi); below 70 kpsi it uses f = 0.9. Override it if you read the chart differently.

4.6 – 4.7 · Notes pp. 43–45

From S′e to Se: the Marin factors

The primed value S′e comes from an ideal specimen: small, polished, room temperature. Your part is none of those, so you correct it: Se = ka kb kc kd ke km S′e. Watch which factor costs the most.

S′e = 0.5 Sut for Sut ≤ 1400 MPa, otherwise 700 MPa (100 kpsi). ka = a·Sutb (Table 6-2, MPa). kb = 1.24d−0.107 for 2.79 ≤ d ≤ 51 mm, 1.51d−0.157 for 51 < d ≤ 254 mm. Non-rotating parts use the equivalent diameter de (0.37d for a round, 0.808√(hb) for a rectangle). kd is interpolated from Table 6-4.

4.8 – 4.10 · Notes pp. 49–51

Fluctuating stress on the σa–σm diagram

A tensile midrange stress opens cracks and lowers fatigue strength; a compressive one helps. Each criterion draws a boundary between infinite life (inside) and finite life (outside). The load line from the origin through your operating point shows where it would cross each boundary if the loads scaled up together.

Loaded with Example 6.2 (kPa). Use any consistent unit.

S-N data come from fully reversed tests, so N = (σ/a)1/b cannot take σa directly when σm ≠ 0. Convert first to the equivalent fully reversed stress from Goodman: σa/σrev + σm/Sut = 1. This tool treats σm ≥ 0; for compressive midrange, check n = Se/σa and yielding.

4.10 · Notes p. 52

Combined loading: collapse everything into von Mises

On a rotating shaft with a constant transverse force and a constant torque, bending is fully reversed while torsion is steady. Combine all alternating components into σ′a and all midrange components into σ′m, each with its fatigue stress concentration factor, then use one criterion. 4.11 · Notes pp. 53–54

Notches matter for every material in fatigue

Under static loading we apply stress concentration only to brittle materials. Under fatigue loading we apply it to ductile and brittle materials alike, softened by the notch sensitivity q: Kf = 1 + q(Kt − 1). Stronger steels and larger fillet radii push q toward 1.

Default: Example 4.3 shoulder, D/d = 38/32 ≈ 1.19 and r/d ≈ 0.094 give Kt ≈ 1.65 from Fig. A-15-9.

Notch sensitivity q
Kf = 1 + q(Kt − 1)

Curves use the Neuber fit behind Figs. 6-20 and 6-21 for steels. Read the charts on exams; use this to check your reading. q = 0 means notch-insensitive (Kf = 1); q = 1 means fully sensitive (Kf = Kt).

Example 4.1 · fully reversed, finite life

Sizing a square cantilever for 104 cycles

A 0.6 m cantilever of AISI 1080 HR with a b × b square section carries F = 2000 sin ωt N at the free end. It must survive 104 cycles with n = 1.5. Assume kb = 0.85. Find b.

  1. Material. Table A-20 for 1080 HR: Sut = 770 MPa, Sy = 420 MPa.
  2. S′e. Sut < 1400 MPa, so S′e = 0.5(770) = 385 MPa.
  3. Marin factors. Hot-rolled: ka = 57.7(770)−0.718 = 0.488. kb = 0.85 (given), kc = 1 (bending), kd = ke = km = 1.
  4. Se = (0.488)(0.85)(385) ≈ 160 MPa.
  5. Sf(104). Sut = 111.7 kpsi gives f ≈ 0.83 (Fig. 6-18), so fSut ≈ 642 MPa. a = 642²/160 ≈ 2575 MPa, b = −⅓ log(642/160) ≈ −0.201. Sf = 2575(104)−0.201 ≈ 404 MPa.
  6. Stress. The maximum moment is at the wall: M = (2000)(0.6) = 1200 N·m. For a square section σa = Mc/I = 6M/b³.
  7. Design. n = Sf/σa = 1.5 → σa = 269 MPa → b³ = 6(1200)/(269 × 106) = 2.68 × 10−5 m³ → b ≈ 30 mm. Small differences in reading f shift this by a few tenths of a millimeter.
Example 6.2 · fluctuating stress, cycles to failure

Is the life infinite? If not, how many cycles?

σmax = 60 kPa, σmin = −20 kPa, f = 0.9, Sut = 80 kPa, Syt = 65 kPa, Se = 40 kPa. Use modified Goodman.

  1. Components. σa = |60 − (−20)|/2 = 40 kPa, σm = (60 − 20)/2 = 20 kPa.
  2. Goodman. nf = 1/(40/40 + 20/80) = 0.8 < 1, so the life is finite.
  3. Why not N = (σa/a)1/b directly? The S-N line was built from fully reversed tests (σm = 0). We need the fully reversed stress that does the same damage.
  4. Equivalent reversed stress. σrev = σa/(1 − σm/Sut) = 40/(1 − 0.25) = 53.3 kPa.
  5. S-N constants. a = (0.9 × 80)²/40 = 130 kPa, b = −⅓ log(72/40) = −0.085.
  6. Life. N = (53.3/130)−1/0.085 ≈ 3.4 × 104 cycles.
Example 4.4 · combined loading

Steady torsion plus alternating bending

Se = 280 MPa, Sy = 420 MPa, Sut = 560 MPa. Steady torsional stress 90 MPa, alternating bending stress 175 MPa. Find the static factor of safety (von Mises) and the fatigue factor of safety (mod-Goodman and Gerber).

  1. Sort the components. σa = 175, σm = 0, τa = 0, τm = 90 MPa.
  2. Static. Peak von Mises: σ′max = √(175² + 3·90²) = 234 MPa, so ny = 420/234 ≈ 1.79.
  3. Von Mises components. σ′a = 175 MPa; σ′m = √3 · 90 = 156 MPa.
  4. Mod-Goodman. nf = 1/(175/280 + 156/560) = 1/0.903 ≈ 1.11.
  5. Gerber. Solve nσa/Se + (nσm/Sut)² = 1 for n: nf ≈ 1.37. Gerber is less conservative than Goodman, as the diagram shows.
